# Instrucciones para el Proyecto Pages

## Idioma

Este proyecto se documenta tanto en español como en inglés. Todos los archivos de documentación deben mantener esta dualidad lingüística.

## Propósito del Proyecto

El proyecto Pages es un repositorio que contiene una colección de proyectos web interactivos y aplicaciones de demostración. Incluye diferentes aplicaciones como WebArena (explorador de temas de color), esfera 3D interactiva, Sudoku con tema Nord, generador de galería NFT con algoritmos matemáticos y otros proyectos web.

## Componentes Principales

- **WebArena**: Aplicación web interactiva que permite explorar diferentes paletas de colores para modos claro y oscuro
- **Esfera 3D**: Visualización interactiva de una esfera 3D utilizando Three.js
- **Sudoku Nord**: Implementación del juego clásico de Sudoku con tema visual Nord
- **Generador de Galería NFT**: Aplicación web full-stack para generar y visualizar galerías de imágenes NFT con algoritmos matemáticos fractales (Mandelbrot, Julia, Perlin Noise, Sierpinski, Koch Snowflake) y efectos procedurales
- **Temas**: Colección de herramientas para explorar diferentes paletas de colores
- **Péndulo Doble Caótico**: Simulación interactiva de un péndulo doble mostrando comportamiento caótico con parámetros ajustables, física en tiempo real y efectos de rastro visual

## Funcionalidades

- Proyectos web interactivos y responsivos
- Implementación de temas claro y oscuro
- Código fuente disponible y bien documentado
- Documentación en múltiples idiomas (español e inglés)
- Aplicaciones full-stack con procesamiento backend
- Implementaciones de algoritmos matemáticos y fractales
- Simulaciones físicas interactivas

## Estructura del Proyecto

- `/Arena` - Proyecto WebArena
- `/esfera-3d` - Esfera 3D interactiva
- `/sudoku-nord` - Juego de Sudoku con tema Nord
- `/caotic_pendulum` - Simulación de péndulo doble caótico
- `/img-generador` - Generador de Galería NFT (Full-stack)
- `/themes` - Colección de temas y paletas de colores
- `README.md` - Documentación en inglés
- `README_ES.md` - Documentación en español
- `QWEN.md` - Instrucciones para Qwen CLI
- `.chat_log/resumen_conversacion.md` - Registro de conversaciones

2. Asegurar que los enlaces bilineales estén presentes en los archivos README

## Consideraciones Especiales

- Este repositorio sirve como portafolio de proyectos web interactivos
- Cada subproyecto es independiente y debe mantener su propia documentación
- La documentación general debe proporcionar una visión general coherente de todos los proyectos
- Se debe mantener la compatibilidad con navegadores modernos
- Los proyectos full-stack requieren configuración adicional de backend
- Los algoritmos matemáticos y fractales son una característica distintiva del nuevo proyecto NFT
